## Agentic AI, in practice

I designed and built a **four-layer multi-agent system on Anthropic Claude** for sales communication: CRM context, commercial reasoning, regional and cultural localization, and personal writing voice. It uses **governed read-only Salesforce access**, confidence self-scoring with human-in-the-loop routing, a no-fabrication rule and a full audit trail, across 20+ agent modules.

It started as my own initiative and is now a **company-sponsored pilot in validation**. The code is internal, so it isn't published here. I'm happy to walk through the architecture in an interview.

I also build Claude skills and MCP servers for code quality and code review, mostly in Python and C.
